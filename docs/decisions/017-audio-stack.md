# Audio Stack

**Work in progress. Nothing here is decided yet.**

This document will own which audio daemon an OpinionatedArch machine runs, and whether it is installed on every machine or only where it is asked for.

[What is OpinionatedArch](../general/000-what-is-opinionatedarch.md) names the audio daemon among the choices Arch leaves to whoever installs it and this project takes once, so a general document promises the answer while no decision holds it. [Remaining](../state/001-remaining.md) carries it as a pending decision, and the baseline it could otherwise have belonged to is itself undecided, in [Package Baseline](013-package-baseline.md).
